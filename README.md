******Car Sales Dashboard – Power BI
Project Overview******

The Car Sales Dashboard is a data visualization and business intelligence project developed using Microsoft Power BI. 
The primary objective of this project is to analyze car sales performance, identify key business trends, and present meaningful insights through interactive visualizations and performance indicators.

The dashboard provides a consolidated view of sales data, enabling users to monitor business performance, evaluate sales trends, and make data-driven decisions.

**Objectives**

Analyze overall car sales performance and revenue trends.
Track key performance indicators (KPIs) related to car sales.
Identify sales patterns across different vehicle categories and time periods.
Present complex sales data through clear and interactive visualizations.
Support informed business decisions through data-driven insights.
Tools and Technologies
Microsoft Power BI Desktop – Dashboard development and data visualization.
Power Query – Data cleaning and transformation.
DAX (Data Analysis Expressions) – Calculated measures and KPI development.
Data Visualization – Interactive charts, graphs, and summary indicators.
Key Features
Interactive dashboard for exploring car sales data.
KPI cards for monitoring important sales metrics.
Trend analysis to understand changes in sales performance over time.
Visual comparisons of sales across relevant categories.
User-friendly layout for efficient data interpretation.
Interactive filters and slicers, where implemented, for customized analysis.
